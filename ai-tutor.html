1. How Smart Switch Works

Smart Switch lets you control connected electrical devices from the app.

Depending on the device, communication can use Wi-Fi, Bluetooth, an IP address, ESP8266, ESP-01, ESP32, HTTP or MQTT.

2. Adding a Device

Open Add Device and enter the information for your switch.


You may need:

  • Device name
  • Device type
  • Wi-Fi connection
  • Bluetooth connection
  • IP address
  • Port
  • HTTP or MQTT protocol

3. Wi-Fi Connection

Wi-Fi allows Smart Switch devices to communicate across a network.

Make sure the device and controller are connected to the correct network when using local IP control.

4. Bluetooth

Bluetooth can be used for supported nearby devices.

Bluetooth availability depends on the hardware and browser/device support.

5. ESP8266, ESP-01 and ESP32

These controllers can connect physical switches to Smart Switch.

The controller receives commands from the application and controls the connected relay or electrical circuit.

6. Controlling a Switch

Once a device has been added, its control card will appear in My Devices.

Press the visible switch button to change its state.

7. Diagnosing Problems

If a device does not respond, check these things:


  1. Check that the device has power.
  2. Check the Wi-Fi connection.
  3. Check the IP address.
  4. Check the port.
  5. Check the selected protocol.
  6. Check whether the ESP controller is running.
  7. Try reconnecting the device.

8. Device Offline

If a device appears offline, first check power and network connectivity.

For IP-based devices, verify that the configured IP address still belongs to the device.

9. Electrical Safety

Smart Switch controls can operate electrical equipment. Always make sure the hardware installation is properly protected and isolated.

Do not work on live electrical circuits.
